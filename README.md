**Loan Approval Prediction Model** 
**Project Overview**

This project builds a machine learning model to predict loan approval status based on applicant financial and demographic information. The goal is to help financial institutions evaluate loan applications more efficiently by identifying whether a loan should be approved or rejected.
The project follows a complete data science workflow including:

- Exploratory Data Analysis (EDA)
- Data preprocessing
- Feature preparation
- Model training
- Model evaluation

**Dataset**

The dataset used in this project contains information about loan applicants, including financial details and loan-related attributes.
Typical features include:
- Applicant income
- Loan amount
- Credit history
- Employment status
- Other applicant financial indicators

Target Variable

loan_status

1 → Loan Approved

0 → Loan Rejected
